Docker install

The fastest way to get RackForge running.

Welcome
Installation
Docker Proxmox LXC Deploying to your infra Project structure

Requires Docker + the Compose plugin (docker compose version) on the target host.

# requires Docker + the Compose plugin
git clone https://github.com/stefpeerlings/rackforge.git
cd rackforge
cp .env.example .env                              # set DOMAIN
cp api/rackforge.env.example api/rackforge.env     # set RACKFORGE_ADMIN_PASSWORD
docker compose up -d --build

.env controls the public-facing domain Caddy serves on; api/rackforge.env holds the app's own secrets (admin password, and optionally SMTP/Google OAuth/license key — see the comments in the example file for each). Neither file is committed to git.

What gets started

  • api — the Python API (zero pip dependencies; only the openssl CLI is added, for license-key verification), with a named volume for plans.db and avatars.
  • web — Caddy with the static site baked in. Automatically requests a Let's Encrypt certificate for DOMAIN (or plain HTTP if DOMAIN=localhost, for local/LAN testing — also set RACKFORGE_SECURE_COOKIE=0 in api/rackforge.env in that case).
Log in at /admin (user admin, password from rackforge.env) to paste a license key under License — it takes effect immediately, no restart needed. api/issue_license.py (the vendor-only key-signing tool) is deliberately excluded from the image.

Note that /admin (the operator panel) and the planner itself are separate account systems: visit /main and sign up for a regular account to actually start planning racks — the admin login is only for managing the instance (users, sessions, audit log, license).

Updating

Rebuild after a git pull:

docker compose up -d --build
