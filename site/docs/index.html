RackForge is a self-hosted rack-planning app: drag equipment into a virtual rack and track U-space and power draw as you go. It's one Python process (standard library only) backed by SQLite, fronted by Caddy — no database server, no build step, no dependency tree to audit.

Two ways to run it

  • Docker — the fastest way to get RackForge running on any Linux host or LXC that has Docker installed. Recommended for most people.
  • Bare-metal on Ubuntu — installs directly onto the host as a systemd user service behind a system-installed Caddy.

Both paths end up in the same place: a running API on port 8080, a Caddy reverse proxy handling /api/* and /admin/*, and a bootstrap admin account you log into to configure everything else (license key, SMTP, Google OAuth) from the admin panel — no config file editing needed after the initial setup.

Tiers & licensing

RackForge ships as one codebase with tier-gated limits, unlocked by a signed license key entered under Admin → License, no restart required. See the tiers page for the full Community / Pro / Enterprise comparison. Community requires no license key and runs fully self-hosted, free, forever.
