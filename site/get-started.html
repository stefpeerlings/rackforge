Get started

Self-hosted means it runs on your own infrastructure. Pick the path that fits.

Docker

The fastest way to get RackForge running on any Linux host or LXC that has Docker installed. Requires Docker + the Compose plugin.

# requires Docker + the Compose plugin
git clone https://github.com/stefpeerlings/rackforge.git
cd rackforge
cp .env.example .env                              # set DOMAIN
cp api/rackforge.env.example api/rackforge.env     # set RACKFORGE_ADMIN_PASSWORD
docker compose up -d --build

Bare-metal (Ubuntu)

Installs directly onto the host as a systemd user service. Caddy is installed automatically if it isn’t already present.

# one line — installs Caddy, the API, and starts the service
git clone https://github.com/stefpeerlings/rackforge.git rackforge-src \
  && cd rackforge-src && bash install.sh
